# 简历上传文件类型选择功能——测试用例

## 1. 功能概述

简历管理页「简历录入」新增上传前文件类型选择：原生单选按钮（radio）提供 **Word文档（蓝色）/ PDF文档（红色）/ 纯文本TXT（灰色）** 三个互斥选项。选定类型后：

- 文件选择对话框按所选类型过滤（accept 动态绑定）；
- 选择不符合所选类型的文件时前端立即拦截并给出友好提示；
- Word/PDF 文件由后端 `POST /api/resumes/upload`（multipart）提取文本后填入「简历原文」；TXT 保持原有前端 FileReader 读取逻辑；
- 后端对扩展名白名单（.doc/.docx/.pdf/.txt）、文件大小（≤2MB）、内容有效性二次校验。

默认选中「纯文本TXT」，与历史版本行为保持一致，粘贴录入流程不受影响。

## 4. 验收结论

- API 层（TC-04/05/06 后端提取、TC-11/12/14/15/16/17）：**11/11 通过**。三种类型真实文件提取文本正确（Word 1402 字、PDF 1640 字、TXT 1651 字，岗位关键词齐全），非法后缀/无后缀/老 .doc/空文件/超 2MB/无文本 PDF 均被正确拦截并返回友好提示。
- 浏览器层（TC-01~10、TC-13、TC-18~20）：**全部通过**。radio 颜色（蓝 rgb(64,158,255) / 红 rgb(245,108,108) / 灰 rgb(144,147,153)）与互斥正确；accept 随类型动态切换；类型不匹配即时拦截且文本框不变；Word/PDF/TXT 三种文件经 UI 上传后均正确填入原文并支持提交入库；类型切换不丢失已填内容；粘贴录入回归正常。
- 回归确认：粘贴录入、解析并保存、匹配/历史/统计流程不受影响，`POST /api/resumes` 接口保持不变，向后兼容。
